# CSUI - Dasar-Dasar Pemrograman 1 (DDP1)

Repositori ini berisi kumpulan tugas, laboratorium, latihan, dan kode program untuk mata kuliah **Dasar-Dasar Pemrograman 1 (DDP1)** di **Fakultas Ilmu Komputer, Universitas Indonesia (Fasilkom UI)**.

---

## 📌 Deskripsi

Mata kuliah **Dasar-Dasar Pemrograman 1** merupakan pondasi awal pembelajaran ilmu komputer dan pemrograman di Fasilkom UI. Pembelajaran berfokus pada pemahaman konsep dasar logika komputer, pemecahan masalah (computational thinking), dan implementasi algoritma menggunakan bahasa pemrograman **Python**.

## Cara Menggunakan

### Prasyarat
Pastikan Anda telah memasang **Python 3.x** di perangkat Anda.

Cek versi Python yang terpasang melalui terminal/command prompt:
```bash
python --version
# atau
python3 --version
```

### Kloning Repositori
Untuk mengunduh dan menjalankan kode secara lokal:

```bash
git clone https://github.com/VickyIbr/CSUI-DDP1.git
cd CSUI-DDP1
```

### Menjalankan Berkas Kode
Jalankan berkas Python menggunakan perintah:

```bash
python <nama_file>.py
```
